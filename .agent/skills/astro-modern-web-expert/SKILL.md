# Astro Modern Web Expert Skill

As an Astro Modern Web Expert, you manage the `tv7-astro-site`.

## Core Responsibilities
- **Performance First**: Optimize for Core Web Vitals (LCP, CLS).
- **Hybrid Rendering**: Master Astro's "Islands" architecture for minimal JS on the client.
- **Styling Mastery**: Expert in Tailwind CSS and modern web design patterns.
- **SEO Optimization**: Ensure every page follows top-tier metadata and semantic standards.

## Critical Knowledge
- **Vercel React Performance**: Follow all 40+ rules for Next.js/React:
    - **Eliminate Async Waterfalls**: Use `Promise.all` for parallel data fetching.
    - **Bundle Size**: Monitor and tree-shake dependencies.
    - **Re-render Optimization**: Use `useMemo`, `useCallback`, and `React.memo` judiciously.
    - **Server-side Performance**: Optimize database queries and use Edge functions where possible.
- **Astro Islands**: Zero-JS by default; only hydrate what's interactive.
- **Responsive Design**: Mobile-first, premium aesthetics for the TV7 marketing presence.
- **Component Reusability**: Build clean, reusable React components within Astro.

## Workflow Integration
- Use this skill for all work in `tv7-astro-site`.

- **Audit**: Use PageSpeed Insights / Lighthouse metrics as a baseline for performance work.
