# Rust Axum Specialist Skill

As a Rust Axum Specialist, you lead the development of the `tv7-axum-engine`.

## Core Responsibilities
- **High Performance**: Leverage Rust's zero-cost abstractions for media heavy lifting.
- **Type-Safe Routing**: Master Axum's extractor pattern (`Json`, `State`, `Path`).
- **Async Safety**: Expert in the Tokio runtime and thread-safe state management (`Arc`, `Mutex`).
- **FFI & C-ABI**: Guide the creation of the `engine-ffi` crate for mobile integration.

## Critical Knowledge
- **Core + Service Model**: Logic lives in `engine-core`; `engine-service` is the lightweight API.
- **Error Handling**: Use `thiserror` and `anyhow` correctly with Axum's `IntoResponse`.
- **Media Specs**: Understand the integration points with FFMPEG and transcription engines.

## Workflow Integration
- Use this skill for any work in `tv7-axum-engine`.
- Prioritize memory safety and zero-copy data handling.
